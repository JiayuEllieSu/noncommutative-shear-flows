# Noncommutative Shear Flows and Chaotic Advection: An Area-Preserving Map Model
A computational theory project for PHY630 (Fluid Mechanics).

## Overview

This project explores how simple horizontal and vertical shear flows can combine to produce complicated tracer motion. The focus is on the relationship between incompressibility, area-preserving transformations, noncommutative matrix multiplication, and material stretching.

The computational model uses idealized two-dimensional shear maps and periodic boundaries. It is a model of passive-particle advection, not a full Navier–Stokes simulation. Stretching and rearrangement of tracers will be distinguished from molecular mixing, which also involves diffusion.



## Reproducing the computational experiments

The [research poster](poster.pdf) summarizes the model and conclusions. All results and figures are generated by [`shear_flows.py`](shear_flows.py), using NumPy and Matplotlib as listed in [`requirements.txt`](requirements.txt). This is a computational study of passive-particle advection, not a laboratory experiment or a Navier-Stokes simulation.

### Setup and run

~~~bash
git clone https://github.com/JiayuEllieSu/noncommutative-shear-flows.git
cd noncommutative-shear-flows
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
~~~

On Windows, activate the environment with `.venv\Scripts\activate` (Command Prompt) or `.venv\Scripts\Activate.ps1` (PowerShell). The script runs without a graphical display (Matplotlib uses the `Agg` backend), prints numerical summaries, and saves CSVs and figures to the repository's `data/` and `figures/` directories. Re-running it overwrites those generated files. Dependencies are not version-pinned, so small floating-point or PDF rendering differences are possible between environments.

**Reproduction requires no command-line flags:** the experiment parameters are defined near the top of `shear_flows.py`.

The initial positions use \(r=0.12\sqrt{U}\) and \(\theta=2\pi V\), for independent uniform \(U,V\); all protocols start with the *same* 16,000 particles. In tracer figures, colors distinguish the initially left and right halves of the disk, **not** concentrations.

### Exact maps and simulation procedure

For two prescribed divergence-free shear stages with strengths \(a=\gamma_H\tau\) and \(b=\gamma_V\tau\),

\[
A(a)=\begin{pmatrix}1&a\\0&1\end{pmatrix},
\qquad
B(b)=\begin{pmatrix}1&0\\b&1\end{pmatrix}.
\]

The code sets \(A=A(1)\), \(B=B(1)\), and uses these **two-stage** maps, repeated for \(n\) cycles:

| Protocol | Matrix applied each cycle | Meaning |
| --- | --- | --- |
| One direction (`single`) | \(A^2\) | Two horizontal shears |
| Alternating (`alternating`) | \(M=AB=\begin{pmatrix}2&1\\1&1\end{pmatrix}\) | Vertical, then horizontal shear |
| Opposite sign (`opposite`) | \(C=A(1)B(-1)=\begin{pmatrix}0&1\\-1&1\end{pmatrix}\) | Negative vertical, then horizontal shear |

Multiplication is **right-to-left**: \(AB\) applies \(B\) first. All matrices have determinant 1, hence preserve area. For the integer-strength experiments, the particle update is `(points @ matrix.T) % 1`, giving discrete maps on the unit torus.

## Quantitative findings and interpretation

### Material stretching and the Lyapunov exponent

The program calculates the maximum stretching factor for the **unwrapped** \(n\)-cycle matrix:

\[
S_n=\sigma_{\max}(M^n)
=\sqrt{\lambda_{\max}\!\left((M^n)^\mathsf{T}M^n\right)}.
\]

This is the largest **singular value**, representing the greatest amplification of an infinitesimal material separation, not (in general) the largest eigenvalue of \(M^n\). Since \(\det M=1\), stretching is balanced by contraction in another direction, so material area stays constant.

For \(M=AB\), the matrix is symmetric and has eigenvalues

\[
\lambda_\pm=\frac{3\pm\sqrt5}{2},\qquad
S_n=\lambda_+^n,\qquad
\chi=\lim_{n\to\infty}\frac{\log S_n}{n}
=\log\lambda_+\approx0.962424\ \text{per cycle}.
\]

Thus the alternating protocol stretches exponentially. The one-direction control satisfies
\(A^{2n}=\begin{pmatrix}1&2n\\0&1\end{pmatrix}\) and
\(S_n=n+\sqrt{n^2+1}\), so its stretching is **algebraic**, even though it can increase significantly. The opposite-sign matrix satisfies \(C^6=I\), so its stretching is bounded and its tracer patch recurs.

### Coarse-grid particle-count variance

The program counts tracers \(N_j(n)\) in each of \(K=32^2=1024\) bins, with mean \(\bar N=N/K\), then computes

\[
V_n=\frac1K\sum_{j=1}^{K}
\left(\frac{N_j(n)}{\bar N}-1\right)^2.
\]

A **smaller \(V_n\)** means more even bin occupancy *at this chosen resolution*. Even independent, uniformly sampled particles have sampling noise, giving

\[
\mathbb E[V_{\mathrm{uniform}}]
=\frac{K-1}{N}=\frac{1023}{16000}
=\boxed{0.0639375}.
\]

This reference is **not** zero and is **not** a diffusion or molecular-homogenization threshold.

### Numerical comparison

The following values are taken from the saved [stretching](data/stretching.csv) and [count-variance](data/coarse_counts.csv) CSVs. All runs start from \(V_0=19.320624\).

| Two-stage protocol | Maximum stretch \(S_{10}\) | Coarse variance \(V_6\) | Coarse variance \(V_8\) |
| --- | ---: | ---: | ---: |
| One-direction shear | 20.049876 | 8.727448 | 6.741296 |
| Alternating shear | **15126.999934** | **0.066544** | **0.066416** |
| Opposite-sign shear | 1.618034 | 19.320624 | 18.968120 |
| Independent-uniform reference | N/A | 0.063938 | 0.063938 |

- **Alternating shears:** \(S_{10}\) is about **754 times** the one-direction control. The cycle-6 coarse variance is only about **4.1% above** the independent-uniform sampling reference, indicating very even occupancy on the 32 × 32 grid. This reflects substantial *coarse-scale redistribution*, not necessarily molecular mixing.
- **One-direction shear:** Despite increasing material deformation, the cycle-6 count variance is roughly **131 times** that of the alternating protocol. Repeating the same shear direction is less effective at redistributing tracers at this resolution.
- **Opposite-sign shear:** \(C^6=I\) and \(V_6=V_0\). Its stages do not commute, yet the patch returns to its initial shape after six cycles. **Noncommutativity alone does not guarantee exponential stretching or chaotic transport.**

### Why the trace determines the growth regime

For general strengths,

\[
M(a,b)=A(a)B(b)=
\begin{pmatrix}1+ab&a\\b&1\end{pmatrix},
\qquad \det M=1,\quad \mathrm{tr}\,M=2+ab.
\]

A repeated fixed matrix has exponentially growing directions precisely when

\[
|2+ab|>2
\quad\Longleftrightarrow\quad
ab>0\ \text{or}\ ab<-4.
\]

In those hyperbolic regimes the largest Lyapunov exponent is
\(\chi=\operatorname{arcosh}(|2+ab|/2)>0\). For \(-4<ab<0\), powers stay bounded. At the boundaries \(ab=0\) and \(ab=-4\), the exponent is zero, although nontrivial matrices can still exhibit algebraic stretching. The scan in [`data/regimes.csv`](data/regimes.csv) tests this result across \(ab\in[-6,4]\).

The distinction matters: **eigenvalues and trace** classify the *long-run* growth regime, while **singular values of \(M^n\)** measure *finite-cycle* stretching. They cannot generally be substituted for each other.

### Limitations: advection is not diffusion

1. **No molecular diffusion:** The model moves tracers but has no diffusive term \(\kappa\nabla^2c\). Advective stretching creates thin filaments that diffusion *could* subsequently smooth. Coarse counts near the sampling benchmark do not establish fine-grained homogenization.
2. **Resolution dependence:** \(V_n\) depends on the grid size, number of tracers, and initial patch. A different grid can produce different values.
3. **Idealized periodic map:** The smooth planar shears motivate the matrices, but the integer-strength modulo-one matrix map is not the time map of a globally smooth periodic velocity field on the torus. Noninteger \(a,b\) in the trace-regime study describe **planar matrices**, not the periodic-tracer simulation.
4. **No turbulent flow simulation:** These are exact linear shear stages and a discrete kinematic advection model, not a solution to turbulent Navier-Stokes equations or an estimate of real experimental mixing times.
